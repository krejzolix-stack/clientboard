# ClientBoard

Mini CRM do zarządzania klientami i statusem realizowanych projektów.

## Demo

Strona online:

https://krejzolix-stack.github.io/clientboard/

## Funkcje

- dodawanie klientów
- zapisywanie adresu e-mail i notatek
- statusy: Nowy / W trakcie / Gotowe
- wyszukiwanie klientów
- filtrowanie według statusu
- usuwanie klientów
- automatyczny licznik klientów
- zapis danych w localStorage
- responsywny wygląd

## Technologie

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

## O projekcie

ClientBoard to prosta aplikacja typu CRM do organizowania bazy klientów. Użytkownik może dodawać klientów, przypisywać im statusy, zapisywać notatki oraz szybko wyszukiwać i filtrować dane.

Projekt powstał w ramach mojej nauki JavaScriptu, pracy z danymi, filtrowania, wyszukiwania oraz localStorage.
